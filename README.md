# OTP-Verification

A single-page OTP (One-Time Password) verification system with JavaScript validation.

## Features

- Generate random 6-digit OTP
- Input field validation
- Auto-focus navigation between input boxes
- Real-time validation feedback
- Mobile-responsive design

## Key Functions

### JavaScript Functions

- `generateOTP()`: Generates a random 6-digit OTP
- `inputValidation()`: Validates user input in real-time
- `autoFocusNext()`: Automatically moves focus to the next input field
- `verifyOTP()`: Compares user input with generated OTP
- `resetForm()`: Clears all input fields and resets the form

### CSS Features

- Responsive input boxes
- Visual feedback for valid/invalid inputs
- Smooth transitions and animations
- Mobile-friendly layout

## How to Use

1. Open the application in a web browser
2. A random OTP will be generated
3. Enter the OTP digits in the input boxes
4. System validates the entered OTP
5. Receive success/error feedback
